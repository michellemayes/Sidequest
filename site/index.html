Four one-click prompts

Pick what the agent should do.

Hover any message, open Sidequest, and click a prompt or press its number. Each one gets the message, the thread, the sender and any attached files.

1 Investigate

Find out why

Reproduces the problem, traces it to the code, explains it and recommends a fix. Changes nothing.

2 Fix

Ship the fix

Finds the root cause, makes the smallest fix, adds a test, gets lint and tests passing, and commits.

3 Review

Check the PR

Reviews the pull request, branch or diff the message points at, bugs first. Changes nothing.

4 Ask

Ask the code

Type a question right in the menu. The agent reads the relevant code and answers it.

Linked a ticket?  Messages that link Linear, GitHub or Jira get a prompt that fixes that ticket on a branch named for it, like linear/data-3051-…, issue/123-… or jira/ABC-123-…. Add prompts of your own in one line of config.
Live status on the message

The message tells you where it's got to.

A small mark under the message keeps up with the session: working, commits, the pull request, the merge. Click it to jump straight back into the session.

  • Hover for the details: uncommitted changes, the PR's link.
  • Pull requests are looked up with gh when it's signed in.
  • The menu leads with Back to Fix, so you never cut a duplicate branch.

How it works

It rides on the Slack app you already have open.

Slack's desktop app is built on Electron. Sidequest adds a small overlay to it over the DevTools Protocol, and a local daemon does the rest.

A fresh worktree

git worktree add on a new branch from origin/main, so your own checkout stays exactly as you left it.

A full prompt

The message, its thread, the permalink and any screenshots or logs are written into the worktree for the agent.

Your agent starts

In a new terminal tab, in the background, or in the Claude or ChatGPT desktop app. Your call.

Slack keeps up

The daemon watches commits, the pull request and the agent's reply, and the message's mark follows along.

Your agent, your terminal

Bring the tools you already use.

Switch with one command. Run any prompt with a different agent, say Review with Codex while Fix stays on Claude Code.

The Mac app

Keep every session in view, beside Slack.

Start sessions from Slack, follow them in the app. Sessions are grouped by what needs you, and the Dock icon counts what's waiting.

  • Edit and post the agent's reply, or send a follow-up, right from the session.
  • Headless sessions get a live conversation, the diff, and a terminal.
  • Signed, notarized and self-updating. It carries its own engine, so it's the only thing to install.
