Four one-click prompts

Pick what the agent should do.

Hover any message, open Sidequest, and click a prompt or press its number. The agent gets the message, the thread, who sent it, and any screenshots or logs attached.

1 Investigate

Find out why

Reproduces the problem, traces it to the code, explains it and recommends a fix. Changes nothing.

2 Fix

Ship the fix

Finds the root cause, makes the smallest fix, adds a test, gets lint and tests passing, and commits.

3 Review

Check the PR

Reviews the pull request, branch or diff the message points at, bugs first. Changes nothing.

4 Ask

Ask the code

Type a question in the menu. The agent reads the relevant code and answers it.

Ticket prompts. Messages that link a Linear, GitHub or Jira ticket get a prompt that fixes that ticket on a branch named for it: linear/data-3051-… issue/123-… jira/ABC-123-…. Want your own? A few lines of config add a prompt to the menu.
Live status

Slack and the app keep up with every session.

A small mark under the message follows the session from working to merged, and the app's activity timeline fills in as it goes. Click either to jump back in.

  • Commits, the pull request, the reply and the merge, each as it happens.
  • Pull requests are looked up with gh when it's signed in.
  • The Dock icon counts the sessions that need you.

Replies you approve

The agent drafts. You post.

When it's done, the agent writes a short answer for the thread: what it found, or what it changed and why. Edit it in the app or in Slack, and post it as you.

  • Nothing goes out without your click (⌘↵ posts it).
  • Every reply says which agent wrote it, so the thread knows.
  • Send a follow-up from the box under the session.

How it works

It rides on the Slack you already have open.

Slack's desktop app is built on Electron. Sidequest adds a small overlay to it over the DevTools Protocol, and a daemon on your Mac does the rest.

1

A fresh worktree

git worktree add on a new branch, so your own checkout stays exactly as you left it.

2

A full prompt

The message, its thread, the permalink and any attached files, written into the worktree.

3

Your agent starts

In a new terminal tab, in the background, or in the Claude or ChatGPT desktop app.

4

You follow along

Commits, the pull request and the agent's reply show up on the message and in the app.

Your agent, your terminal

Bring the tools you already use.

Swap agents or terminals with one command. Or pick one per prompt: Review with Codex while Fix stays on Claude Code.

Private by default

Nothing leaves your machine unless you post it.

No Slack app to install

No bot token and no admin approval. Sidequest reads the message from the Slack window you already have open.

Your checkout stays put

Every session works in its own worktree on its own branch. Sessions commit; they don't push until you ask.

You approve every reply

The agent's answer waits for you to read, edit and post. Reactions and auto-posting stay off unless you turn them on.
